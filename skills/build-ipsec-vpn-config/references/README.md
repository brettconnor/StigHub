# Web reference index

Keep external sources used for IPSec VPN guidance in this directory. Record
the source title, URL, access date, and the specific claims it supports;
distinguish Cisco documentation from community or other secondary material.
Do not treat a reference as proof that a configuration works on every IOS XE
platform or release.

- [IOS XE IPsec and IKEv2 references](iosxe-ipsec.md) — sources consulted
  while cleaning the IOS-XE site-to-site IPsec template.
- [WAN ingress filtering](wan-ingress.md) — ACL attachment, IPv6 neighbor
  discovery limitations, and the VPN-transport-only ingress policy.
- [Login banner](login-banner.md) — operator-supplied IOS-XE management
  recipe for the applicable notice-and-consent banner requirement.
- [Session limits](session-limits.md) — per-user SSH session control and
  the distinction between recipe values and SSP-defined policy.
